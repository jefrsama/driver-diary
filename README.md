# Дневник смен водителя

Небольшой дневник поездок: сервер на Django отдаёт список и сводку за выбранный день, клиент на Vue показывает смену и умеет добавлять поездку.

Время дня считается по Астане (UTC+5): поездка попадает в тот календарный день, когда она началась.

## Что сделано

- `GET /api/days/` — даты, в которые уже есть поездки.
- `GET /api/days/YYYY-MM-DD/` — поездки за день и сводка: число поездок, выручка, комиссия, сумма на руки, разбивка наличные/карта.
- `POST /api/trips/` — новая поездка. Сумма должна быть больше 0, окончание позже начала, оплата `cash` или `card`.
- Повторная отправка той же поездки (тот же `id` и те же данные) не создаёт вторую запись: сервер возвращает уже сохранённую. Если `id` совпал, а сумма или время другие — ответ `409`.
- Сводка и отбор за день считаются в базе.
- Тесты: расчёт сводки и защита от дублей.

На руки = выручка − комиссия.

## Как запустить

Нужны Python 3.12 и Node.js.

Бэкенд:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_trips
python manage.py test
python manage.py runserver
```

Фронтенд, вторым окном:

```powershell
cd frontend
npm install
npm run dev
```

Открыть http://localhost:5173 . Запросы к `/api` проксируются на http://127.0.0.1:8000 .

`seed_trips` загружает пример из задания и ещё несколько поездок на 1 и 2 октября 2026. Повторный запуск дубли не создаёт.

На Linux и macOS виртуальное окружение активируется так: `source .venv/bin/activate`.
